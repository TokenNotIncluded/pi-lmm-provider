# LMM for Pi artwork

<img src="./icon.svg" width="128" height="128" alt="LMM for Pi" />

`icon.svg` is the editable plugin mark. The four folded-ribbon paths are retained
from the LMM API [project-owned logo geometry](https://github.com/TokenNotIncluded/lmm-api/blob/ebabe6fcc89dfbfb049bd562666b17f699d90a38/.github/assets/logo-geometry.json),
scaled without changing their shapes. A path-only Pi monogram distinguishes this
client within the LMM plugin family. No font or external image is loaded.

The canvas is 256 × 256. Rounded outer corners remain transparent; the charcoal
tile keeps the warm neutral symbol readable on light and dark surfaces. This
asset follows the package's AGPL-3.0-only license.
